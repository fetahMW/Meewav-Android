## Bugs et divergences

1. **Création UI non conclue sur 5570 :** aucune Room LIVE sous le titre exact n'a été trouvée après le tap final du RUN 1, mais l'exécution du handler n'avait pas été prouvée. L'instrumentation complémentaire est bloquée par le stockage de l'AVD. Le succès manuel LIVE sur S22 interdit de généraliser cette observation à l'application.
2. **FLAKY navigation/rendu Rooms :** écran noir lors de l'entrée initiale (>45 s, récupération ≤69 s), puis après redémarrage de l'AVD A (encore noir à +60 s, accueil ≤120 s). Aucune cause applicative précise isolée.
3. **Incidents de harnais/accessibilité :** précondition DM-detail sans dock, placeholder titre non exposé, casse d'assertion, carte B chevauchant le FAB, et expiration du driver Maestro B. Premières preuves conservées ; aucun de ces échecs n'est transformé en PASS propre par un rerun.

**PREMIÈRE DIVERGENCE :** le premier échec chronologique était une précondition de flow incorrecte (DM détail). Pour le wizard, le premier point non démontré est l'entrée dans le handler après le tap final ; la Room backend était absente lors de la recherche. La cause reste ouverte. Ce scénario est classé **BLOCKED BY HARNESS / INCONCLUSIVE** pour la suite du diagnostic sur 5570.
